# gplayeraudio 
Минималистичный аудиоплеер, написанный на kotlin

## Основные возможности
- Material you - приятный дизайн и оформление
- Вся музыка в одном месте 
- Работает в фоне
- Полноценный аудиоплеер с возможностью переключения музыки

### Компиляция 
Чтобы скомпилировать и запустить этот проект вам понадобится среда разработки **Android Studio** или любая другая среда, позволяющая работать с файлами kotlin.<br><br>
В Android Studio выберите **File -> New -> New Project...**
```bash
git clone https://github.com
```
Далее после того как вы скачали проект скомпилируйте и запустите 
```bash
./gradlew assembleDebug
```
Или используйте release
```bash
./gradlew assembleRelease
```
