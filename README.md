# gplayeraudio 
Минималистичный аудиоплеер, написанный на kotlin

## Основные возможности
- Material you - приятный дизайн и оформление
- Вся музыка в одном месте 
- Работает в фоне
- Полноценный аудиоплеер с возможностью переключения музыки

### Компиляция 
Чтобы скомпилировать и запустить этот проект вам понадобится среда разработки **Android Studio** или любая другая среда, позволяющая работать с файлами kotlin
